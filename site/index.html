Fully between-subjects

Each participant completes all three stories, but only one out the six measures (relevance, normality, controllability, same, different, endorse). Every measure/'experiment' has its own URL.

Each story has three different versions, whereby each subject only sees one of them.

First set of measures (as in Experiment 1)

  • Relevance/experiment1/relevance/
  • Controllability/experiment1/controllability/
  • Normality/experiment1/normality/

Second set of measures (as in Experiment 2, but excluding 'Undo')

  • Same/experiment2/same/
  • Different/experiment2/different/
  • Endorse/experiment2/endorse/
